Detailed Description

An Action Client in Python.

Author
Alessandro Vercellino
Version
1.0
Date
15/03/2025

Publishes to:
/robot_velocity_kmh

Subcribes to:
/robot_velocity

Service :
/goal_status

This script allows a user to: Send goals to an Action Server and track their status. Cancel goals that are currently being processed. Monitor the number of goals reached and canceled via a ROS service. Convert and publish robot velocity in km/h.
