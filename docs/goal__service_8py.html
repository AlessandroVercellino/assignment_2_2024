Detailed Description

A service for a goal in Python.

Author
Alessandro Vercellino
Version
1.0
Date
15/03/2025

Publishes to:
/cmd_vel

Subcribes to:
/odom

Service :
/go_to_point_switch

This script implements a simple go-to-point behavior for a mobile robot using proportional control for both yaw and linear movement. The robot first aligns its yaw to face the target position and then moves forward until it reaches the desired position within a defined tolerance.
